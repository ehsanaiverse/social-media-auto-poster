# AutoPoster Frontend

Premium React frontend with Three.js animations and Framer Motion for the Social Media Auto-Poster.

## Setup

```powershell
cd frontend
npm install
```

## Run

```powershell
npm run dev
```

The frontend will be available at `http://localhost:3000`.

## Tech Stack

- React 18 + TypeScript
- Vite for build tooling
- Three.js + @react-three/drei for 3D animations
- Framer Motion for smooth animations
- Tailwind CSS for styling
- Glassmorphism design system

## Features

- 3D animated background with floating particles
- Real-time job status dashboard
- One-click run and scan controls
- Responsive glassmorphism UI
- Gradient text effects
- Animated status badges
